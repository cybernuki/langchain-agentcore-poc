# LangChain + Amazon Bedrock AgentCore — Production Agent POC

This repository is a **proof of concept (POC) of a production-grade AI agent** built with
[LangChain](https://www.langchain.com/) and deployed on
[Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/).

## Goal

Validate the path from a local LangChain agent to a production deployment on Bedrock AgentCore,
covering:

- Agent orchestration with LangChain (tools, memory, retrieval).
- Model access through Amazon Bedrock.
- Hosting, scaling, and session isolation with AgentCore Runtime.
- Observability, identity, and memory using AgentCore services.

## Status

Early stage — the project is being built from scratch.
